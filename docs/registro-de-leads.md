# Registro de contatos e serviços

Modelo para preenchimento manual pelo proprietário. Nenhum dado real ou os cinco serviços mencionados foi importado como conversão.

| --- | --- | --- | --- | --- | --- | --- | --- |
| | | WhatsApp / telefone | | Não comprovada | Novo / em atendimento / orçamento / fechado / perdido | | |

Use uma referência interna para acompanhar o mesmo contato sem contá-lo novamente a cada clique. Guarde informações pessoais e identificadores de clique apenas em registro restrito, conforme a configuração de consentimento aplicável. Não os coloque nos eventos Analytics ou em arquivos públicos do site.

Separar origem declarada pelo cliente de origem comprovada por identificadores. A presença de UTMs no site, o total de cliques e o total agregado de serviços não bastam para importar conversões offline. Para uma importação futura, o responsável pelo Ads deve conferir identificador suportado, ação de conversão, datas e consentimento de cada registro.
